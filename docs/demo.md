# README demo

Captured on Windows on 2026-11-19 with the installed v0.1.0-preview.3 bundle:
Herdr 0.1.16, Codex CLI 0.169.1 and GPT-6.1 Sol. The screenshot shows a real
Codex conversation and the image rendered by Codex below its completed reply.
The local PNG was prepared before the conversation; it was not generated by the model.

The demo used a dedicated Herdr app home and a terminal-only layout. Existing
private project lists and remote connection details are outside this layout.
The PNG is an unedited 1180×840 frame from `herdr-app shot`.

## Reproduce

Open a new PowerShell terminal in Herdr Images, change to the repository root,
and launch the bundled Codex in its normal rich transcript mode:

```powershell
$env:TERM = 'xterm-ghostty'
codex --no-daemon
```

`TERM=xterm-ghostty` advertises the Kitty graphics capability of Herdr's Ghostty
terminal renderer. It is needed for this Windows preview demo: the default
Herdr terminal identification did not select a working graphics protocol in
this test. This assignment affects only the current shell and its children.
The installer does not currently add this capability setting automatically.
Do not use `--no-alt-screen` for this demo; that selects the text/scrollback mode
instead of the rich owned transcript required by reply image previews.

Ask Codex:

> Show docs/images/demo.png inline in your reply. Reply with one short sentence
> and a Markdown image link. Do not modify files.

The captured conversation used a dedicated folder containing the same image as
`demo.png`, with this prompt:

> Show demo.png inline in your reply. Do not run tools or modify files. Reply with
> one short sentence and a Markdown image link to demo.png. This is the Herdr +
> Codex README demo.

Codex returned:

```markdown
This is the Herdr + Codex README demo.

![Herdr + Codex README demo](demo.png)
```

The app captured the actual resumed conversation in rich transcript mode, with
Kitty graphics enabled. No screenshot compositing or generated conversation UI
was used. The screenshot and the sample image are included in this repository.
